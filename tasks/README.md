# Case-study tasks

Application names and the named map workspace have been generalized for publication. The private application source is not included, so these task descriptions cannot reproduce the original workload on an arbitrary project.

| Task | Work | Mode |
|---|---|---|
| 1 | Trace a station action through generation of a VDA 5050 order; identify functions and files | Read-only |
| 2 | Trace map export through the runtime | Read-only |
| 3 | Remove the layout-inspector back button and close it using Escape or right-click; implement and test | Code changes |
| 4 | Import/export a project in its native format for transfer between instances | Code changes |

The task3 run1 summaries carry the inspector-task label, but private agent answers performed the map-export tracing task without edits or tests. That triplet is excluded from the main cohort and is retained separately for transparency. It is not silently reassigned to task2.

The prompts embedded in `scripts/historical/` are sanitized snapshots of the available scripts, not proof of the exact historical submitted prompts. For example, the task4 result texts retain an original leading `wI` typo while the available script says `I`.
